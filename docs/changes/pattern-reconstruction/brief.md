# Brief: 模糊图纸高清重建

- Change ID: `pattern-reconstruction`
- Status: implemented
- Owner: project team
- Last updated: 2026-10-20

## Problem

网络上的已有拼豆图纸常因压缩、截图或转发而模糊。普通图片锐化会猜测文字和边缘，无法保证每个网格与色号仍然准确，也不能继续编辑或无损放大。

## Desired outcome

用户可以导入仍能辨认规则网格的模糊图纸，校准网格边界与行列数，逐格重建为当前色卡的颜色索引，复核待确认格，然后进入编辑器继续修改或导出真正的 SVG 矢量图与高清 PNG。

## In scope

- 独立“高清重建”页面与主导航入口
- PNG、JPEG、WebP 图纸导入
- 行列数、四边网格边界校准和叠加预览
- 避开中心文字的稳健颜色采样
- 可选原图图例色号约束，排除原图未使用的相近色号
- CIEDE2000 色卡匹配和待确认格标记
- 后台 Worker 逐格识别
- 单格人工色号修正
- 带坐标、色号和十格粗线的 SVG / PNG 导出
- 将结果作为新图纸送入现有编辑器

## Out of scope

- 对完全不可见的信息进行生成式猜测
- 自动识别严重透视、弯曲或局部遮挡的网格
- 通用文字 OCR 或水印移除
- PDF 分页打印

## Acceptance criteria

- [x] 输出由网格、矢量文字与色块重新绘制，不嵌入原位图
- [x] 模糊色号文字不会主导格子颜色采样
- [x] 色差过大或候选过近的格子会标记为待确认格
- [x] 用户可以修正单格色号并导入编辑器
- [x] 识别计算不阻塞主线程
- [x] Chromium / WebKit 端到端回归通过

## Fragile assumption

第一版假设输入仍有规则、可对齐的矩形网格。若网格存在严重透视或遮挡，用户需要先在外部校正图片；系统不会用生成式内容填补不可见格子。
