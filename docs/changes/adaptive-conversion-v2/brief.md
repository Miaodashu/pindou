# Brief: 自适应图片转拼豆管线 V2

- Change ID: `adaptive-conversion-v2`
- Status: implemented
- Owner: project team
- Last updated: 2026-10-23

## Problem

现有转换先把原图直接缩到目标网格，再进行边缘检测和色卡匹配。轮廓两侧颜色会在缩放阶段混合，细线、眼睛、高光和文字等小特征在进入量化算法前已经丢失；逐格独立匹配还会产生可铺性较差的孤立色块。

## Desired outcome

在不改变图纸存档格式、不引入服务端处理的前提下，提升图片到 Mard 拼豆图纸的轮廓保留、颜色稳定性和可拼装性，并保证同一输入与设置得到确定性结果。

## In scope

- 原图分辨率的边缘分析和轻度边缘保留滤波
- 每个目标格的 5×5 / 7×7 多点自适应采样
- 平坦区域使用线性 RGB 平均，轮廓区域使用主导真实颜色
- 限色方案的贪心选择后交换优化
- 受真实边缘保护的 1～3 格孤立区域清理
- OpenCV.js/WASM 与 Canvas 降级路径的一致输出语义

## Out of scope

- 生成式 AI 重绘、云端模型和主体语义分割
- 非规则或变形网格
- 自动改变用户选择的图纸宽高
- 旧图纸存档迁移

## Acceptance criteria

- [x] 边缘检测发生在降至拼豆网格之前
- [x] 平坦颜色、透明覆盖和中心细线具有单元测试
- [x] 强边缘上的单格细节不会被空间清理删除
- [x] 限色模式在贪心选色后执行有界、确定性的交换优化
- [x] Worker 仍可在 OpenCV 失败时使用 Canvas 路径生成图纸
- [x] 转换报告标识 V2 并展示自动清理的孤立格数量
- [x] V1 经典采样保留为内部可选回退管线
- [x] 透明像素隐藏 RGB 不会污染不透明图案边缘
