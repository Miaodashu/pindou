# 小尺寸图纸转换优化交接

## 当前状态

实现完成，最终规格与仓库规范差异审查均无剩余 findings。

## 实现摘要

- 新增独立的小图优化策略规划与回缩模块。
- 图片转换结果区新增三种优化模式及“恢复标准结果”。
- 优化结果仍使用用户设置的最终图纸尺寸，并按最终格数校正报告中的计数指标。
- 保留标准结果的细节容量评估，避免中间放大图纸让细节评分产生虚高。
- 优化结果上的生成参数发生变化时，重新生成会先回到标准结果，建立新参数对应的可信细节基线。
- 全屏精修点击“完成”、右上角关闭或按 Esc 时，外层图纸预览会同步当前图纸的最新尺寸、格子与颜色数量，不再停留在转换时的旧快照。

## 样图观察

- 复杂动漫截图：自动清晰保持整体稳定；色块优先能减少背景碎点；轮廓优先可能增加色彩和边界噪声，因此不作为默认推荐。

## 已知限制

- 极小图纸的物理格数仍是细节上限；优化只能重新分配有限格子，不能完整保留原图所有细节。
- 轮廓优先对照片或复杂背景可能产生更多碎点，界面已明确标注其适用场景。
