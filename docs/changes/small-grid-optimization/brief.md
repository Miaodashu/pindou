# 小尺寸图纸转换优化

## 背景

图片直接转换为较小图纸时，五官、轮廓和主体色块容易在一次采样中丢失。两张验证样图分别覆盖复杂动漫截图与高对比线稿，现有标准转换仍需保留，不能强制替换用户的生成策略。

## 目标

- 标准图纸生成后提供清晰可见的“小图优化”入口。
- 提供“自动清晰”“轮廓优先”“色块优先”三种可重复选择的结果。
- 优化过程中保持用户要求的最终图纸宽高不变。
- 用户可以一键恢复标准转换结果。
- 转换继续在浏览器本地执行，不上传图片。

## 方案口径

- 优化模式先在不超过 `300 × 300` 的中间图纸上转换，再使用保细节缩小算法回到目标尺寸。
- “自动清晰”使用均衡策略，最多 12 色，保留用户选择的图片类型。
- “轮廓优先”使用最接近原图策略和插画模式，优先保留五官与细线。
- “色块优先”使用最少颜色策略和插画模式，最多 8 色，优先减少碎点和复杂背景。
- 首次生成仍使用标准转换；优化是结果不理想时的用户主动选择。

## 验收标准

1. 三种模式均可在结果区选择，当前模式有可访问的选中状态。
2. 优化前后图纸宽高和格子数量一致。
3. 恢复标准结果后不再显示优化模式为已应用。
4. 参数已修改但尚未重新生成时，不允许对过期结果执行优化。
5. 核心策略有单元测试，转换、优化与恢复流程有 Chromium 和 WebKit 端到端覆盖。
