# Brief: 结构感知图片转拼豆管线 V3

- Change ID: `structural-conversion-v3`
- Status: implemented
- Owner: project team
- Last updated: 2026-10-23

## Problem

V2 能在缩图前保护边缘并清理小型孤立色块，但网格相位仍固定从裁切区域左上角开始，每格也只用一个代表色进入色卡匹配。半格级偏移会破坏细线、五官和文字；逐格独立选色无法同时兼顾轮廓反差与大色块连续性。

## Desired outcome

在继续使用浏览器 Web Worker、OpenCV.js/WASM 和 Mard 色卡的前提下，让转换同时考虑网格对齐、每格候选色、邻域结构与图纸尺寸承载能力，并保留 V1/V2 可回退管线。

## In scope

- 九候选亚格网格相位评分与自动对齐
- 根据原图边缘分布选择自适应 Canny 阈值
- 每格保留最多三个源颜色候选
- 每格保留最多五个 Mard 候选色及匹配代价
- 有界、确定性的边缘约束空间联合优化
- 仅在平滑大区域启用的稀疏有序抖色
- 细节承载评分和更大图纸尺寸建议
- 转换报告展示实际运行的 V3 步骤

## Out of scope

- 云端图片处理、生成式 AI 和语义重绘
- 自动修改用户选择的图纸尺寸
- 实物色卡测量和显示器颜色校准
- 非矩形或可变形拼豆网格

## Acceptance criteria

- [x] 强轮廓可以驱动亚格网格相位选择
- [x] 平坦图片保持中性相位，不产生无意义偏移
- [x] 多源色单元保留多个色卡候选
- [x] 平坦区域弱碎色可被结构优化合并
- [x] 强边缘两侧的真实反差不会被空间平滑抹除
- [x] 抖色仅使用相近色并保持稀疏、确定性
- [x] 复杂图片只显示尺寸建议，不自动修改图纸
- [x] V3 失败时仍可使用现有 Worker 错误与 Canvas 降级路径
