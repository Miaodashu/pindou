# Handoff: 结构与线条感知图片转拼豆管线 V4

- Change ID: `structural-conversion-v3`
- Current status: implemented and verified
- Last updated: 2026-10-25

## Completed

- 保留 V3 的网格相位、候选颜色、空间联合优化、受控抖色与细节承载评分。
- 新增“照片 / 插画与线稿 / 像素图”三种内容模式，每种模式都展示适用场景、处理重点和取舍说明。
- 插画与线稿模式改用更密集采样，通过暗色线条候选、线条强度和保护掩码提高眉毛、嘴部等细线的存活率。
- 受保护细节不会被结构优化或小区域清理误删；像素图模式跳过柔化与抖色。
- 照片模式在低边缘区域增加受约束的邻域净化，减少背景孤立杂点。
- 修复“建议尺寸先修改宽高、旧单元格按新尺寸重排”的状态错误；旧结果始终按生成时尺寸显示。
- 参数改变后显示待重新生成提示并禁用全屏精修；应用同比例建议尺寸时直接重新生成。
- 全屏精修新增每个色号的“隐藏当前颜色”“隐藏其他颜色”和“显示全部”，显隐只影响编辑视图。
- 新增大图转小图：按真实覆盖面积缩小精修后的图纸，并对边界与目标格中心细节给予受控权重。
- 生成小尺寸副本前显式保存大图；小图也独立保存，并通过图纸 ID 关联在刷新后恢复“回到大图原稿”的入口。
- 生成结果签名包含完整色卡指纹，切换或更新色卡后旧结果会明确要求重新生成，不会被新色卡错误解释。
- 裁切弹框采用固定页头、剩余空间内容区和固定页脚；桌面端右侧生成设置可独立滚动，窄屏回退为整个内容区滚动。

## Known issues and risks

- 线条识别是浏览器端确定性启发式，不是语义模型；极低对比度、低清晰度或未命中采样点的线条仍可能需要手工补画。
- 背景净化只处理低边缘且邻域高度一致的杂点，刻意不强行抹平纹理背景。
- 大图和小图都会写入本地数据库，最新一次派生关系可跨刷新恢复；项目尚无完整的历史图纸列表，管理多组历史版本仍需要后续项目管理入口。
- 色号隐藏是精修辅助视图，不改变图纸数据，也不影响导出结果。
- Mard 数字参考色不能保证与不同批次实物豆完全一致。

## Recommended next action

建立固定的照片、动漫线稿、像素图、透明 PNG 和复杂背景基准集，记录相同尺寸下三种模式的轮廓召回、背景杂点数和人工盲选结果，再校准线条与净化阈值。
