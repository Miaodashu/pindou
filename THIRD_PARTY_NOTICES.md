# Third-party notices

## Mard screen-reference palette

The bundled standard Mard 221 code list and screen-reference HEX values were
validated on 2026-10-19 against the user-provided capture of the 2026 revised
Mard chart at:

https://www.pixel-beads.com/zh/mard-bead-color-chart

The source page describes these values as screen approximations. They are
versioned inside this repository so an upstream page change cannot silently
alter existing projects. Physical bead color can vary with production batch,
lighting, material finish, and display calibration; purchasing decisions should
be checked against a physical chart.
